PIXEL CLIPBOARD 2.4 - JAVA DESKTOP APP
====================================

START
  Run PixelClipboard-Setup-2.4.0.exe to install as a normal Windows app.
  Choose whether to add Start menu and desktop shortcuts during setup.
  Windows Installed apps will contain the installed application.
  Or launch PixelClipboard.exe directly from the portable app folder.
  Inside Settings, WINDOWS SETUP opens setup or the project's download page.

  This is a compiled Java Swing application with its own bundled runtime.
  No PowerShell, VBS, Java installation, or administrator rights are needed
  to run the packaged application. Keep its app and runtime folders beside
  PixelClipboard.exe. To move the app, copy the entire dist\PixelClipboard
  folder, not just the EXE.

USE
  Click a task to edit it. Changes save automatically after a short pause.
  Click the checkbox to mark it complete; completed text is crossed out.
  Click any blank paper row to add at the first available position.
  Clicking farther down adds the next unused row without gaps, even when
  the previous task is still empty.
  Press Enter to insert below the task you edit, or Ctrl+N to add a task.
  Enter works on empty tasks too, and focuses the new task immediately.
  Backspace deletes an empty task. On nonempty tasks it edits text normally.
  Task text sits directly on the parchment in a bundled pixel font.
  Delete with x; undo with Ctrl+Shift+Z or from SETTINGS.
  The wooden gear at the bottom-left opens Settings: keep-on-top, undo,
  and all keyboard shortcuts.
  Right-click a task for Cut, Copy, Paste, Move Up/Down, and Delete.
  Click CHECKLIST to edit the title. Your title is saved automatically.
  Enter finishes editing the title; Escape cancels the title edit.
  Drag the wooden surround to move the app.
  Drag any outer edge or corner to resize it.
  Double-click the top wooden surround to maximize or restore.
  Taller windows show more tasks per page; the artwork frame stays crisp.
  Use << and >> to change pages. Next creates a new page when at the end:
    1/1 -> Next -> 2/2 -> Previous -> 1/2.
  Pages are retained when empty and after reopening the app.
  New pages start with a blank task ready for typing or Enter.
  Add inserts on the current page; tasks keep their page assignments.
  When a page fills, extra tasks continue on the next page.
  The _ button minimizes to the taskbar. X saves and exits.

KEYBOARD
  Enter               Insert and focus a task below the current one
  Ctrl+N              Add and focus a task on the current page
  Ctrl+Enter          Complete or reopen the task being edited
  Backspace           Delete an empty task; otherwise erase a character
  Up / Down           Edit the previous or next task, including across pages
  Ctrl+PageDown       Next page
  Ctrl+PageUp         Previous page
  Ctrl+Shift+Z        Undo task deletion (up to 100 during this session)
  Ctrl+Up / Ctrl+Down Move the task being edited
  Ctrl+Shift+D        Delete the task being edited
  Ctrl+P              Toggle keep on top
  Escape              Finish task editing, or cancel a title edit
  F1                  Open Settings
  Tab / Shift+Tab    Move keyboard focus
  Space               Toggle the focused checkbox

YOUR SAVED TASKS
  The Java app reads the original PowerShell app's state file directly:
    %APPDATA%\PixelClipboard\state.json
  Tasks, title, completion, pin preference, window size, and position are retained.
  Only one Java instance runs at a time to prevent competing saves.
  Atomic saves use a temporary file and keep state.json.bak for recovery.
  Damaged JSON is preserved before any recovery or fresh save.
  Errors are recorded in %APPDATA%\PixelClipboard\error.log.
  Close the old PowerShell widget before opening the Java app.
  Archived PowerShell files are in legacy\; use the Java launchers above.

BUILD FROM SOURCE
  Java source: src\main\java\pixelclipboard\
  Set JAVA_HOME to a JDK 21 or newer, then run build.cmd.
  The build also detects the project-local JDK in .tooling\jdk\.
  build.cmd jar builds only the executable JAR.
  A full build packages dist\PixelClipboard\PixelClipboard.exe with jpackage.
  Close the Java app before rebuilding its generated dist folder.
  No Maven, Gradle, downloaded libraries, or network access are needed to build
  once a JDK is available. The portable app needs no installer.
  Run test.cmd for regression and window tests using isolated test data.
  Run package-installer.cmd with WiX 3.14.1 available to build the installer.
